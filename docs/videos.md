# Видео и ролики

Все медиа лежат в `public/` и попадают в сборку как есть, поэтому здесь только
то, что реально показывается на сайте.

## Что используется

- `videos/biba-mowing-timelapse.mp4` — таймлапс испытаний BiBa (секция «Демо»,
  играет по кнопке, грузится только метаданные).
- `videos/robbox-vendor-demo.mp4` — РОББОКС-комивояжёр (там же).
- `rviz-demo.mp4`, `led-animation.mp4` — короткие зацикленные ролики без звука;
  раньше были гифками на 8 и 3 МБ, теперь 0,8 и 0,3 МБ. Запускаются, только
  когда попадают в кадр, при `prefers-reduced-motion` показываются с кнопками.

Фоновых видео в герое больше нет: вместо них рисованная SVG-сцена
(см. [hero-scenes.md](hero-scenes.md)). Файлы `robot-video-1..3.mp4` удалены
из `public/`, при необходимости их можно достать из истории git.

## Как готовить новые ролики

- **Формат**: MP4, H.264, `yuv420p`, `-movflags +faststart`, без звука для
  зацикленных вставок.
- **Разрешение**: до 1280×720 для демо, короткие вставки — по исходнику.
- **Размер**: до 5–10 МБ на демо-видео, до 1 МБ на зацикленную вставку.

Гифку в MP4:

```bash
ffmpeg -i input.gif -vf "scale=trunc(iw/2)*2:trunc(ih/2)*2,format=yuv420p" -c:v libx264 -preset slow -crf 24 -movflags +faststart -an output.mp4
```

Вертикальное видео в горизонтальное с обрезкой:

```bash
ffmpeg -i IMG_9682.MOV -vf "crop=ih*16/9:ih" -c:v libx264 -crf 23 -preset medium -c:a aac -b:a 128k output.mp4
```
